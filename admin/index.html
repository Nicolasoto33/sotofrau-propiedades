Publicar una propiedad sin errores

Checklist rápido de Sotofrau Propiedades.

  1. Usa un ID único. No reutilices el número de otra propiedad.
  2. Revisa operación, estado, ubicación y precio. El precio siempre debe indicar $/CLP o UF.
  3. Selecciona una imagen principal: será la foto más importante de la ficha y de las vistas previas al compartir.
  4. Ordena la galería desde las mejores fotografías hacia las secundarias.
  5. Completa características, descripción, conectividad y requisitos solo cuando correspondan.
  6. Guarda el borrador y utiliza la vista previa antes de llevarlo a publicación.
Las fotografías nuevas se optimizan automáticamente al subirlas desde este panel: se mantiene el encuadre original, se reduce el peso y se guardan en un formato web más eficiente.
